# 007 型チェックに tsrs を使う

- 状態: 採用
- 日付: 2026-11-08

## 背景

型チェックの道具が Rust や Go に移っていく流れに乗りたい。tsrs は Void と同じく VoidZero の道具で、Vite+ も型を使う lint に使う。

Go 版の `tsc` は、読んだファイルを Vite Task が追えないので、検査をキャッシュすると型エラーを見逃した。tsrs なら追える。

## 決めたこと

- `vp run typecheck` を tsrs で動かす（tsconfig ごとに `-p` で回す）
- 版は Vite+ が持つ版にそろえ、2 つの版を入れない

## ほかの案

| 案             | 選ばなかった理由                                                                       |
| -------------- | -------------------------------------------------------------------------------------- |
| `tsc`（Go 版） | 検査をキャッシュできない。同じエラーを出すことは確かめたので、困ったときの戻り先に残す |

## 手放すもの

- 試験版なので、`tsc` と結果が違うことがある（エラーの順番など）
- エディタの TypeScript が別の版だと、まれに結果がずれる
- 上げるときに、出どころ（provenance）を確かめる手間がかかる
