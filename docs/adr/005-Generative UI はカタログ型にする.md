# 005 Generative UI はカタログ型にする

- 状態: 採用
- 日付: 2026-11-14

## 背景

AI の返答の中に部品（選択肢・グラフなど）を出す。作り方は 2 つある。

- カタログ型: AI は、決められた部品の名前と props だけを出す
- マークアップ型: AI が JSX や HTML を書く

## 決めたこと

- カタログ型にする。AI の出力は、部品の種類（`kind`）で分かれる形にし、FE のカタログが種類から部品を選ぶ
- 部品の props は、約束（`packages/contract`）に zod で書く。BE は AI の出力を確かめ、FE は型つきで受け取る
- 最初の版の部品は「選択肢」（押せる部品）と「棒グラフ」（見せる部品）。表は部品にせず、Markdown の表で出す
- 部品も保存し、会話を開き直したときに同じ部品を出す
- 部品は、チャットの機能の中（`apps/web/src/client/components/features/Chat/GenUI/`）に置く
- アプリの AI には Claude を使う。決められた部品と props を正しく選べるかが、カタログ型の要になる

## ほかの案

| 案             | 選ばなかった理由                                                                                        |
| -------------- | ------------------------------------------------------------------------------------------------------- |
| マークアップ型 | 見た目がデザインシステムの外に出る。AI が書いたマークアップを描くことになる。Tailwind が要る（ADR 004） |
| Workers AI     | 日本語と、道具（部品）の選び方が弱め                                                                    |

## 手放すもの

- 部品を足すたびに、約束とカタログの両方を足す
- 外のデータを使う部品（天気・地図）や入力フォームは、ツールの実行まで要るので、最初の版では作らない
