# 006 認証は最初の版に入れ Better Auth を使う

- 状態: 採用
- 日付: 2026-11-15

## 背景

会話を人ごとに保存し、AI の利用料も守りたい。あとから会話に持ち主を足すと、会話の DB と API を作り直すことになる。

## 決めたこと

- 最初の版から、ログインしないと使えないようにする
- ログインの方法は、メールアドレスとパスワード・Google・X。外の登録が要らないメールアドレスとパスワードを先に作る
- Void に組み込まれた Better Auth を使う。認証の API（`/api/auth`）とクライアントは Void が出し、画面は自分で作る
- 認証の API は、oRPC の約束（ADR 002）に入れない
- ログインしていない人は、ルートの読み込みの前に `/login` に移す

## ほかの案

| 案                                 | 選ばなかった理由                                          |
| ---------------------------------- | --------------------------------------------------------- |
| ログインしなくても使える（ゲスト） | すぐ試せるが、会話の持ち主の扱いが増える                  |
| 認証をあとから足す                 | 会話の DB と API を作り直すことになる                     |
| 認証の API を自分で作る            | Void に組み込まれていて、API もクライアントも出してくれる |

## 手放すもの

- 試すのにアカウントの登録が要る
- Google と X は、それぞれのサービスでアプリを登録する準備が要る
- 認証の API は `/rpc` でないので、偽物の BE（ADR 003）を別に用意する
