# Input

1 行の文字を書いてもらうときに使う。メールアドレスやパスワードなど、ログインや新規登録のフォームに置く。

<Canvas of={InputStories.Default} />

## チャットの入力欄との違い

- 会話で送る文は、何行にもなるので、この部品を使わない。チャットの入力欄は、別の部品にする
- この部品は光らせない。画面で光るのは、チャットの入力欄だけ

## 名前

- 読み上げる名前を必ず付ける。ふつうは、見えるラベルと一緒に置く（Field で包む）
- 案内の文字（`placeholder`）を、ラベルの代わりにしない。書き始めると消えるので、何の欄だったか分からなくなる
- 案内の文字には、書き方の例だけを書く（`name@example.com` など）

## 種類と自動入力

- 書くものに合わせて `type` を選ぶ（`email`・`password`・`url` など）。スマートフォンで、合うキーボードが出る
- `autoComplete` を付ける（`email`・`current-password`・`new-password` など）。ブラウザやパスワードの管理の道具が、入れてくれる

## 状態

- 押せない・書けないときは `disabled` を付ける。薄くなり、フォーカスもできない
- 見せるだけで書き換えさせないときは `readOnly` を付ける。面が控えめな色になる。フォーカスはでき、文字を選んでコピーできる
- フォーカスがあるあいだは、線に輪が重なって、太く濃い線になる。文字を書く欄なので、マウスで押したときも出る

## 置き方

- 幅は、置いた親いっぱいに広がる。幅を決めるのは、置く側の親（`className` と `style` は受け付けない）
- 押せる範囲は、高さが 44px 以上ある
