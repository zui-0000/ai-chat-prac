# Button

押すと、その場で何かが起きる操作に使う。別の画面に移るときは、ボタンでなくリンクを使う。

<Canvas of={ButtonStories.WithIcon} />

## 種類

- 主な操作（`variant="primary"`）: その領域でいちばん先に押してほしい操作。赤で塗る。1 つの領域に 1 つだけ置く（一覧なら「新しい会話」、入力欄なら送る・止める）
- ふつうの操作（`variant` を付けない）: 主な操作のほかの操作。控えめな面に置く
- 取り消せない操作（消す・退会など）の種類は、まだ無い。赤がこのサイトの色なので、赤だけでは危ない操作だと伝わらない。確認のダイアログと一緒に、アイコンと言葉で伝える

## アイコン

- 文字の前に、lucide-react のアイコンを子として置ける。大きさはボタンが決めるので、`size` を渡さない
- 文字と一緒に置くアイコンには、何も付けない（lucide-react が読み上げから外す）
- アイコンだけのボタンには使わない。読み上げる名前の付け方が違うので、別の部品にする

## 状態

- 押せないときは `disabled` を付ける。薄くなり、押しても何も起きない
- フォーカスの輪は、キーボードで移ったときだけ出る

## 置き方

- 位置や間隔は、置く側の親が決める（`className` と `style` は受け付けない）
- 押せる範囲は、縦横とも 44px 以上ある
