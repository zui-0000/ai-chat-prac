# IconButton

アイコンだけで、押すと何が起きるかが伝わる操作に使う。返答のコピー、会話の名前の編集など、同じ操作が何度も並ぶ場所で、字を並べずに済ませたいときに置く。

<Canvas of={IconButtonStories.Group} />

## Button との使い分け

- アイコンだけでは何が起きるか伝わりにくい操作は、字の付いた Button にする
- 取り消せない操作（消すなど）は、アイコンだけで置いてよいが、押したあとに確認のダイアログを出す

## 種類

- ふつう（`variant` を付けない）: 塗らない。マウスを乗せたときと押している間だけ、控えめな面を敷く
- 主な操作（`variant="primary"`）: チャットの入力欄の送る・止めるだけに使う。赤で塗る。1 つの領域に 1 つだけ置く

## 名前

- `aria-label` は必ず渡す。読み上げでは、これがボタンの名前になる
- 名前は、押すと何が起きるかを動詞で書く（「コピーする」「送る」）。アイコンの形（「紙のアイコン」）は書かない
- アイコンには何も付けない（lucide-react が読み上げから外す）。大きさはボタンが決めるので、`size` を渡さない

## 状態

- 押せないときは `disabled` を付ける。薄くなり、押しても何も起きない
- フォーカスの輪は、キーボードで移ったときだけ出る

## 置き方

- 位置や間隔は、置く側の親が決める（`className` と `style` は受け付けない）
- 押せる範囲は、縦横とも 44px 以上ある
