# DESIGN.md — AI チャット

このアプリの見た目の決まり。画面や部品を作る前に読む。

色や大きさの値は、ここには書かない。値は `src/client/styles/tokens/` のトークン（CSS 変数）だけに置き、ここではトークンの名前で指す。

## 1. Visual Theme & Atmosphere

毎日使う道具。面は静かな無彩色にして、細い赤い線で囲む。

- **赤は、塗らずに線で使う**。赤く塗るのは、主な操作のボタンだけにする
- **緑は 1 か所だけ**。返答が流れている途中の印にだけ使う
- **光るのはチャットの入力欄だけ**。ほかの面には影も光も付けない
- **暗い配色と明るい配色を持つ**。OS の設定に合わせて切り替わる。作るときは暗い配色を先に考え、明るい配色では土台と面を明るい色に替えるだけにする。線・印・コードの箱の使い方は変えない

画面は、左に会話の一覧、右に見出しの帯・発言・入力欄を置く。

## 2. Color Palette & Roles

色のトークンは 3 段になっている。部品に書くのは、下の 2 段（このサイトの色と、役割の色）だけ。色の材料（`--color-primitive-*`）は書かない。明るい配色と暗い配色は、トークンが切り替える。

### Primary（このサイトの色）

このサイトを表す 3 色。役割の色は、ここを指す。

| トークン                                                        | 色と使いどころ                                                                                                                   |
| --------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `--color-ai-chat-primary`・`--color-ai-chat-primary-foreground` | 赤。主な操作のボタンの塗りと、その上の文字                                                                                       |
| `--color-ai-chat-primary-hover`                                 | 主な操作のボタンに、マウスを乗せたときと押している間の塗り。暗い配色では、暗くしすぎると背景に沈むので、沈まない明るさにとどめる |
| `--color-ai-chat-primary-text`                                  | 赤い文字（名前のラベル・リンク）                                                                                                 |
| `--color-ai-chat-secondary`                                     | オレンジ。赤い線に添える                                                                                                         |
| `--color-ai-chat-accent`                                        | 緑。返答が流れている途中の印                                                                                                     |

- 赤い文字には `--color-ai-chat-primary-text` を使う。`--color-ai-chat-primary` と `--color-frame` を文字の色にしない（暗い面の上で読めない）
- 役割の色があるものは、役割の色のほうを使う（線は `--color-frame`）

### Semantic（役割の色）

| トークン                                          | 役割                                                                     |
| ------------------------------------------------- | ------------------------------------------------------------------------ |
| `--color-frame`                                   | 面を囲む線と、発言のカードのふちの線。線にだけ使い、面を塗らない         |
| `--color-ring`                                    | フォーカスの輪。赤い線や赤いボタンと見分けるため、赤でなく文字の色にする |
| `--color-selected`・`--color-selected-foreground` | 選ばれている状態の面と、その上の文字                                     |
| `--color-error`                                   | 誤りの文字と、誤りのある入力欄の線                                       |

成功・注意の色は、まだ無い。要る部品を作るときに足す。誤りの色（`--color-error`）は、このサイトの赤と同じ色なので、赤だけではエラーや危ない操作だと伝わらない。エラーと取り消せない操作は、アイコンと言葉で伝える。

### Neutral（ニュートラル）

| トークン                                    | 役割                                                                                     |
| ------------------------------------------- | ---------------------------------------------------------------------------------------- |
| `--color-background`・`--color-foreground`  | ページの土台と、本文の文字                                                               |
| `--color-card`・`--color-card-foreground`   | 土台の上にのる面（会話の一覧・見出しの帯・発言）                                         |
| `--color-muted`・`--color-muted-foreground` | 控えめな面（文の中のコード）と、補足の文字                                               |
| `--color-border`                            | 面の中を区切る、飾りの線（会話の一覧と、その下の設定の間など）。形を見せる線には使わない |

### 色を足すとき

色のトークンに置くのは、このサイトの色と、2 つ以上の部品が使う役割の色だけ。部品が増えるたびに足さない。色が要るときは、次の順で考える。

1. 今ある役割の色で書けるなら、何も足さない
2. ほかの部品も使う役割（面・文字・線・状態の種類）なら、役割の名前でトークンに足す。部品の名前を付けない
3. その部品だけの色なら、部品の CSS に書く。値は、上の色から作る（`color-mix()` で混ぜる・薄める）

文字と背景は、4.5:1 以上のコントラストにする。形を見せる線と印は 3:1 以上にする。色の値を変えるときと、新しい組み合わせで使うときは、比を計算して確かめる。

## 3. Typography Rules

### 3.1 和文フォント

OS の書体を使う（Mac・iPhone はヒラギノ角ゴシック、Windows は Yu Gothic UI かメイリオ）。Noto Sans JP は、入れてある環境でだけ使う候補として並べる。

和文の書体は配らない。字が多く、ページに出た字の範囲ごとに取りに行くので、どんな漢字が出るか分からないチャットでは、返答のたびに読み込みが起き、届いたときに書体が差し替わって文字がずれるため。

### 3.2 欧文フォント

欧文も和文と同じ書体で出し、太さと大きさをそろえる。等幅は JetBrains Mono で、コードにだけ使う。等幅は OS ごとの差が大きいので、これだけは配る（`@fontsource-variable/jetbrains-mono`）。英字だけなのでファイルが小さく、コードの箱が出たときにだけ取りに行く。

### 3.3 font-family 指定

`--font-family-sans`（本文は `--font-family-body`）と `--font-family-mono` を使う。部品に書体の名前を直接書かない。

### 3.4 文字サイズ・ウェイト階層

| 役割                           | サイズ                             | 太さ                | 行の高さ                                 | 字間                  |
| ------------------------------ | ---------------------------------- | ------------------- | ---------------------------------------- | --------------------- |
| 見出し（会話の名前）           | `--font-size-16`                   | `--font-weight-700` | `--line-height-body`                     | なし                  |
| 本文（発言）                   | `--font-size-15`                   | `--font-weight-400` | `--line-height-body`                     | なし                  |
| 入力欄                         | `--font-size-16`                   | `--font-weight-400` | `--line-height-170`                      | なし                  |
| 一覧の行                       | `--font-size-14`                   | `--font-weight-400` | `--line-height-body`                     | なし                  |
| フォームのラベル               | `--font-size-14`                   | `--font-weight-700` | `--line-height-body`                     | なし                  |
| フォームの説明・誤り           | `--font-size-14`                   | `--font-weight-400` | `--line-height-body`                     | なし                  |
| ボタンの文字                   | `--font-size-14`                   | `--font-weight-700` | `--line-height-body`                     | なし                  |
| コード                         | `--font-size-13`                   | `--font-weight-400` | `--line-height-170`                      | なし                  |
| 補足（日付の区切り・案内）     | `--font-size-12`                   | `--font-weight-400` | `--line-height-body`                     | なし                  |
| 名前のラベル（発言の上）       | `--font-size-12`                   | `--font-weight-700` | `--line-height-body`                     | `--letter-spacing-14` |
| アプリの名前（一覧の上）       | `--font-size-15`                   | `--font-weight-700` | `--line-height-body`                     | `--letter-spacing-2`  |
| 大きな見出し（ページの題など） | `--font-size-18`〜`--font-size-32` | `--font-weight-700` | `--line-height-120`〜`--line-height-150` | なし                  |

- 強調は、太さ（`--font-weight-700`）で付ける。選ばれている行だけは `--font-weight-500` にする
- `--font-size-12` は、補足とラベルにだけ使う。読ませる文には使わない
- 入力欄の文字は `--font-size-16` より小さくしない。小さいと、iPhone の Safari が、押したときに画面を拡大する

### 3.5 行間・字間

- 行の高さは `--line-height-body`（`--line-height-180` と同じ値）。和文は欧文より行間を広く取る
- 入力欄とコードだけは、少し詰めて `--line-height-170` にする
- 行の高さの段は `--line-height-100` から `--line-height-180` まである。文字が大きいほど詰める
  - `--line-height-100`: 1 行だけのラベルやアイコン
  - `--line-height-120`〜`--line-height-150`: 大きな見出し
  - `--line-height-160`: ボタンやメニューの、短い文
- 本文に字間は付けない。字間を付けるのは、英字の大文字で書く名前のラベル（`--letter-spacing-14`）と、アプリの名前（`--letter-spacing-2`）だけ

### 3.6 禁則処理・改行ルール

- 発言の文には `line-break: strict` と `overflow-wrap: anywhere` を付ける。長い URL やコードが、列からはみ出さない
- `word-break: break-all` は使わない（英単語が途中で切れる）

### 3.7 OpenType 機能

- 本文に `font-feature-settings: "palt"` を付けない（かなが詰まって、長い文が読みにくい）

### 3.8 縦書き

使わない。

## 4. Component Stylings

部品を作るときの、見た目の決まり。線の太さは、囲む線が `--border-width-frame`、ふちの線が `--border-width-edge`。

### Buttons

- 主な操作のボタンは、`--color-ai-chat-primary` で塗り、文字は `--color-ai-chat-primary-foreground`。マウスを乗せたときと押している間は `--color-ai-chat-primary-hover` で塗る。角丸は `--border-radius-8`
- 主な操作のボタンは、1 つの領域に 1 つだけ置く（一覧なら「新しい会話」、入力欄なら送る・止める）
- ふつうの操作のボタンは、`--color-muted` の面に `--color-foreground` の文字を置き、線は付けない。マウスを乗せたときと押している間は、面に `--color-foreground` を少し混ぜる
- 文字と並べるアイコンの大きさは `--size-icon`。アイコンと字の間は `--spacing-8`
- 押したときは少し縮め、マウスを乗せたときと見分ける（動きを減らす設定では縮めない）。タッチの端末では、押している間だけ色を変える。押せないときは薄くする
- アイコンだけのボタンは、ふつうは塗らず、色は `--color-muted-foreground`。マウスを乗せたときと押している間は、`--color-muted` の面を敷き、色を `--color-foreground` にする
- アイコンだけのボタンで塗るのは、入力欄の送る・止めるだけ。塗り方は主な操作のボタンと同じ
- アイコンだけのボタンは、縦横とも `--size-touch-target` の正方形にし、中のアイコンの大きさは `--size-icon-standalone`。角丸は `--border-radius-8`

### Inputs

チャットの入力欄は、この画面でいちばん目立たせる。

- 面は `--color-card`。上のほうにだけ `--color-ai-chat-primary` を少し混ぜ、下へ向かって抜く。どちらの配色でも同じ割合で混ぜ、配色ごとに書き分けない。角丸は `--border-radius-12`
- 囲む線は `--color-frame`。上のふちだけ線を `--border-width-edge` に太くし、その下に、`--color-ai-chat-secondary` を薄めた細い線を重ねる
- 外に `--elevation-glow` の光を出す
- 案内の文字は `--color-muted-foreground`

ログインなどのフォームに置く 1 行の入力欄は、チャットの入力欄と分け、控えめにする。光らせない。

- 面は `--color-card`。囲む線は `--color-muted-foreground` で、まわりの面との差を 3:1 以上にする。角丸は `--border-radius-8`
- 高さは `--size-touch-target` 以上。文字は、3.4 の入力欄の行に合わせる
- マウスを乗せたときは、線を `--color-foreground` にする
- フォーカスの輪は、間をあけずに線に重ねる。入力欄は自分の線を持つので、あけて描くと線が 2 本に見える
- 読み取り専用のときは、面を `--color-muted` にする
- 誤りがあるときは、線を `--color-error` にする。色だけで伝えないよう、下に誤りの文をアイコンと一緒に出す（Field）
- 誤りがあるときは、フォーカスの輪も `--color-error` にする。文字の色の輪だと、フォーカスのあいだ誤りの線が隠れる

### Cards

発言のカード。自分の発言と AI の返答を、同じ作りにして左右だけ反対にする。

- 面は `--color-card`。囲む線は付けない
- 自分の発言は右に寄せ、右のふちに `--color-frame` の線を引く。AI の返答は列の幅いっぱいに置き、左のふちに線を引く
- 線の側の角は丸めない。反対側の角は `--border-radius-12`
- 上に、名前のラベルを `--color-ai-chat-primary-text` で置く

### そのほか

- **面を囲む線**: 会話の一覧の右と、見出しの帯の下に、`--color-frame` の線を引く
- **一覧の行**: 選ばれている行は、面を `--color-selected`、囲む線を `--color-frame` にする。角丸は `--border-radius-8`
- **コードの箱**: どちらの配色でも暗いままにする。専用の色は作らず、箱に `color-scheme: dark` を付ける。箱の中では役割の色が暗い配色の値になるので、面は `--color-background`、文字は `--color-foreground`、補足の文字は `--color-muted-foreground`、線は `--color-border` で書く（フォーカスの輪・スクロールバー・選んだ文字も、暗い配色で出る）。角丸は `--border-radius-8`。箱の中でフォーカスを受けるものは、輪を箱の内側に出し、箱の外にはみ出させない
- **文の中のコード**: `--color-muted` の面で、角丸は `--border-radius-4`
- **返答が流れている印**: 文の終わりに、`--color-ai-chat-accent` の四角を置く
- **フォーカスの輪**: `--color-ring` の輪を、太さ `--border-width-ring` で、部品のふちから同じ幅だけ離して出す。赤い線や赤い塗りと重ねない
- **背景の画像**: 背景に画像を敷くときは、面を半透明にして後ろをぼかし、文字は面の上にだけ置く。そのためのトークンは、画像を入れるときに足す

## 5. Layout Principles

### Spacing Scale

`--spacing-2` から `--spacing-64` まで。4px を基本の単位にする。関係のある要素は近づけ、別のまとまりとの間は広くあける。

| 使いどころ                                   | トークン                       |
| -------------------------------------------- | ------------------------------ |
| 一覧の行と行の間                             | `--spacing-4`                  |
| ボタンの中のアイコンと字                     | `--spacing-8`                  |
| 発言の中の段落と段落の間                     | `--spacing-12`                 |
| 面の内側の余白                               | `--spacing-16`                 |
| 発言と発言の間                               | `--spacing-24`                 |
| アイコンと字の、細かいずれの調整             | `--spacing-2`                  |
| チャットの入力欄のように、広めに取る面の内側 | `--spacing-20`                 |
| 列の上下・面の外側の余白                     | `--spacing-32`                 |
| ページの大きな区切り・ページの外側の余白     | `--spacing-40`〜`--spacing-64` |

### Container

- 発言と入力欄の列は、幅を最大 `--size-message-column` にして、中央に置く
- 会話の一覧の幅は `--size-sidebar`

### Grid

使わない。並べるときは flex と `gap` で書く。

## 6. Depth & Elevation

- 面の重なりは、影でなく、線（`--color-frame`）と面の明るさ（`--color-background` と `--color-card`）で見せる
- 影のトークンは `--elevation-glow` だけ。チャットの入力欄にだけ使う
- ポップアップ（メニュー・ダイアログ）の影は、その部品を作るときに足す

## 7. Do's and Don'ts

### Do（推奨）

- 色・文字・余白・大きさ・線の太さ・角丸・影は、トークンで書く
- 赤は線で使う
- 目立たせるものは、1 つの領域に 1 つにする
- エラーと取り消せない操作は、アイコンと言葉で伝える

### Don't（禁止）

- 色の値や、色の材料のトークンを、部品に書かない
- 赤で面を広く塗らない。赤い線で囲む面を、これ以上増やさない
- 緑を、返答が流れている印のほかに使わない
- チャットの入力欄のほかに、影や光を付けない
- 明るい配色と暗い配色を、部品の CSS で書き分けない
- 書体を 1 つだけ指定しない。本文の行の高さを 1.5 より小さくしない

## 8. Responsive Behavior

### Breakpoints

画面の幅でなく、置かれた場所の幅で切り替える（コンテナークエリ）。境目の値は、部品ごとに決める。幅が足りないときは、会話の一覧を発言の列と並べない。

### タッチターゲット

押せる部品は、縦横とも `--size-touch-target` 以上にする。文の中のリンクは除く。

### フォントサイズの調整

幅が狭くても、本文は `--font-size-15` のままにする。

## 9. Agent Prompt Guide

### クイックリファレンス

- 土台は `--color-background`、面は `--color-card`、文字は `--color-foreground`、補足は `--color-muted-foreground`
- 面を囲む線は `--color-frame`。赤い文字は `--color-ai-chat-primary-text`
- 主なボタンは `--color-ai-chat-primary` と `--color-ai-chat-primary-foreground`
- 角丸は、小さいものから `--border-radius-4`・`--border-radius-8`・`--border-radius-12`
- 本文は `--font-size-15` と `--line-height-body`

### プロンプト例

```text
apps/web/DESIGN.md の決まりで、会話の一覧の行を作って。
面は --color-card、選ばれている行は --color-selected の面に --color-frame の線。
色の値は書かず、トークンだけを使う。
```
