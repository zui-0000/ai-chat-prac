# はじめに

AI チャットの画面の部品と、デザイントークンの見本。見た目の決まりは `apps/web/DESIGN.md` にある。

## 並び

- `UI`: どの画面でも使う部品（`src/client/components/ui/`）
- `Chat`: チャットの画面の部品（`src/client/components/features/Chat/`）
- `DesignTokens`: トークン（`src/client/styles/tokens/`）の見本
- `Guidelines`: 部品をまたぐ決まり（キーボードの操作など）

## 配色を切り替える

上のツールバーの「配色」で、OS に合わせる・ライト・ダークを選べる。部品の見た目は、どちらの配色でも確かめる。

## エージェントから引く

Storybook を起動している間は、addon-mcp が `http://localhost:6006/mcp` で部品とストーリーの情報を返す。
